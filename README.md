# Incident Response

Write-ups from the **stc × Misk Virtual Work Experience: Cybersecurity Incident Response Analysis**, a professional simulation of stc's incident-response lifecycle: identifying and containing threats, analysing attack scenarios, and drafting incident reports.

Each task documents the scenario, the tools and method used, the findings, and the incident report that followed.
